# BG Ultima Valheim

Сборка модов Valheim от BadgeR GameS. Здесь собраны описание сборки, актуальные изменения состава и ссылки на технический патч.

## О сборке

Сборка объединяет моды на интерфейс, снаряжение, ремесло, исследование мира и удобство игры. Основной интерфейс — SeneaL UI; его совместимость с Path of Valheiman реализована отдельным [патчем](https://github.com/ShamaNGameS/-BG-Ultima-Valheim).

## Последние изменения сборки — 16 ноября 2026

- Установлен WeightlessCoins 1.0.1; вес монет в SeneaL UI настроен без второго модификатора веса.
- Для ванильных и модовых хранилищ задано 8 столбцов с сохранением прежнего числа строк. Значения конфигов проверены, но вид сеток в игре нужно перепроверить.
- Удалены BetterTames 0.9.0, Seasonality и мод рюкзаков.
- Обновлены CustomLoadingScreens, Artisan Mastery, Hunter Legacy, TeleportCarts, TeleportCreatures, TeleportEverything и WackysDatabase. Добавлен TeleportBoats как зависимость TeleportEverything.
- В конфигурации Custom Main Menu отключён автоматический показ панели изменений при старте; открыть её можно кнопкой «Изменения».

## Патч SeneaL UI / Path of Valheiman

- Добавлены страницы SeneaL UI для станций Path of Valheiman, включая Стол рунограна и Рунную наковальню, а также интеграции магазина, книги Залов, навыков, характеристик и фильтра добычи.
- Добавлены совместимые ячейки экипировки и сокетов, подсказки предметов и панель прислужников.
- Добавлен значок книги для кнопки «Все рецепты».
- В патче есть попытка подгонки сундука к инвентарю, но по последним скриншотам игрока видимые размеры и расположение не изменились. Исправление интерфейса сундука и падения FPS при его открытии остаётся незавершённым.
- Защита переноса вещей в могилу при переполненном кошельке добавлена, но требует проверки на игровом сохранении.
- Патч 0.6.6 установлен в активную папку игры 16 ноября 2026 г. Игра после обновления ещё не запускалась, поэтому клавиши требуют проверки.

## Панель изменений в игре

Краткие заметки для главного меню хранятся в `BepInEx/config/CustomMainMenu/changelog.txt`. Они доступны по кнопке «Изменения»; автоматическое открытие оставлено выключенным по просьбе игрока. Изменения файла применяются Custom Main Menu без перезапуска игры.

Полный журнал: [CHANGELOG.md](CHANGELOG.md). Там отдельно отмечены подтверждённые действия и проверки, которые ещё предстоят.

## Важное для сетевой игры

TeleportEverything и используемые его модули должны иметь согласованные версии на сервере и у игроков, которым нужна телепортация.
